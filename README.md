# 🌍 Meer Traveler

Hey there! Welcome to **Meer Traveler** — a modern, responsive web application built with React designed for travel enthusiasts who want to explore hidden gem destinations, build custom itineraries, and keep track of their dream vacation spots.

I built this project to deliver a smooth, high-end user experience with gorgeous glassmorphism aesthetics, interactive search filters, and smooth card animations.

---

### ✨ What's Inside? (Features)

- **Immersive Home Page:** Features a stunning hero banner with a quick-search widget and an interactive date selection popup to help users plan ahead.
- **Explore Destinations (`/explore`):** A dynamic grid showcasing trending places with real-time search filtering. Each city card includes ratings, pricing, and a save-to-wishlist button.
- **Smart Trip Planner (`/planner`):** An itinerary builder where travelers can type in their destination, pick custom travel dates, and manage or delete their planned trips easily.
- **Saved Places (`/saved`):** A dedicated wishlist page where users can manage all the cities they've bookmarked for future adventures.
- **Modern UI & Glassmorphism:** Styled from scratch with clean component-level CSS, flexbox/grid layouts, and 3D hover effects.

---

### 🛠️ Tech Stack & Tools

- **Frontend:** React.js, React Router DOM (for seamless multi-page navigation)
- **Icons:** React Icons (`react-icons`)
- **Styling:** Custom CSS, Glassmorphism UI design, Responsive layouts
